# Teka-Teki Nusantara — V16 Android

Ini adalah versi aplikasi Android native-wrapper: seluruh game HTML/CSS/JS dan aset utama dibundel di dalam APK, sehingga game tidak membutuhkan server untuk membuka halaman utama.

## Build APK
Buka folder ini di Android Studio, tunggu Gradle sync, lalu pilih **Build > Build APK(s)**.

Package: `com.ahmaddimyati.tekatakinusantara`
Version: `16.0`

## Catatan
- Game menggunakan aset lokal: logo, foto pencetus, video petunjuk, dan musik.
- WebView hanya menjadi mesin tampilan lokal di dalam aplikasi; game tidak dibuka sebagai tab browser.
- Ukuran file tidak otomatis menentukan kualitas/HD; kualitas visual ditentukan resolusi aset dan rendering.
